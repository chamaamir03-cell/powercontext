# Inventory Search Specification

SPEC_VERSION: v1

## Scope

`inventory.search.search_products` is the single search entry point for the demo
inventory project. It accepts an iterable of `Product` records and returns the
matching page as a list.

## Functional requirements

- REQ-SEARCH-QUERY: `query` matches product name or category, case-insensitively.
- REQ-SEARCH-CATEGORY: `category` is an exact match when supplied.
- REQ-SEARCH-SORT: supported values are `relevance`, `price_asc`, `price_desc`,
  and `rating_desc`; unknown values raise `ValueError`.
- REQ-SEARCH-PAGE: `page` and `page_size` are one-based positive integers;
  invalid values raise `ValueError`.
- REQ-PRICE-BOUNDS: add optional keyword arguments `min_price` and `max_price`.
  Prices are integer cents. Both bounds are inclusive. A missing bound means
  unbounded on that side.
- REQ-PRICE-RANGE: when both bounds are present, `min_price` must be less than
  or equal to `max_price`; otherwise raise `ValueError`.
- REQ-PRICE-VALIDATION: bounds must be integers (not `bool`) and must be
  non-negative; invalid values raise `ValueError`.
- REQ-PRICE-COMBINE: price bounds combine with `query`, `category`, sorting, and
  pagination without changing their existing behavior.

## Verification

- Target tests: `tests/test_price_filter.py`
- Regression tests: `tests/test_regression.py`

The target tests are expected to fail before the price filter exists because the
keyword arguments are not accepted. They must pass after the change, with every

2. Code before the change (inventory/search.py):
```python
from collections.abc import Iterable

from .models import Product

SORT_CHOICES = ("relevance", "price_asc", "price_desc", "rating_desc")


def search_products(
    products: Iterable[Product],
    *,
    query: str | None = None,
    category: str | None = None,
    sort: str = "relevance",
    page: int = 1,
    page_size: int = 10,
) -> list[Product]:
    if page < 1:
        raise ValueError("page must be >= 1")
    if page_size < 1:
        raise ValueError("page_size must be >= 1")
    if sort not in SORT_CHOICES:
        raise ValueError(f"unsupported sort: {sort}")

    results = list(products)

    if query is not None:
        needle = query.strip().lower()
        if needle:
            results = [
                product
                for product in results
                if needle in product.name.lower() or needle in product.category.lower()
            ]

    if category is not None:
        results = [product for product in results if product.category == category]

    if sort == "price_asc":
        results.sort(key=lambda product: (product.price_cents, product.sku))
    elif sort == "price_desc":
        results.sort(key=lambda product: (-product.price_cents, product.sku))
    elif sort == "rating_desc":
        results.sort(key=lambda product: (-product.rating, product.sku))
    else:
        results.sort(key=lambda product: (-product.rating, product.price_cents, product.sku))

    start = (page - 1) * page_size
    stop = start + page_size
    return results[start:stop]

```

3. Target tests (tests/test_price_filter.py):

```python
import pytest

from inventory import all_products, search_products


def skus(products):
    return [product.sku for product in products]


def test_min_price_is_inclusive():
    result = search_products(all_products(), min_price=5000)
    assert set(skus(result)) == {"SKU-001", "SKU-004", "SKU-005", "SKU-007"}


def test_max_price_is_inclusive():
    result = search_products(all_products(), max_price=3499)
    assert set(skus(result)) == {"SKU-002", "SKU-006", "SKU-008"}
    assert "SKU-002" in skus(result)


def test_price_range_combines_with_query_and_category():
    result = search_products(
        all_products(),
        query="hub",
        category="accessory",
        min_price=3000,
        max_price=6000,
    )
    assert skus(result) == ["SKU-003"]


def test_price_range_respects_sort_and_pagination():
    result = search_products(
        all_products(),
        min_price=2000,
        max_price=9000,
        sort="price_asc",
        page=2,
        page_size=2,
    )
    assert skus(result) == ["SKU-003", "SKU-005"]


def test_price_bounds_allow_zero_and_empty_results():
    assert search_products(all_products(), min_price=0, max_price=0) == []


@pytest.mark.parametrize(
    ("min_price", "max_price"),
    [
        (6000, 5000),
        (-1, 5000),
        (0, -1),
        (True, 5000),
        (5000, False),
        (10.5, 5000),
        ("5000", 9000),
    ],
)
def test_invalid_price_bounds_raise_value_error(min_price, max_price):
    with pytest.raises(ValueError):
        search_products(all_products(), min_price=min_price, max_price=max_price)

```
